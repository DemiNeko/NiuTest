# Промпты для моделей

1. [Конвертация документа](01-convert.txt): сохранить исходник, не угадывать неизвестный ключ.
2. [Поиск ответов](02-research-answers.txt): первичные источники, объяснения и честные статусы.
3. [Независимая проверка](03-audit.txt): сверка с оригиналом, пропуски, индексы и неоднозначности.

Приложи исходный документ и, для шагов 2–3, JSON. Независимую проверку желательно поручить другой модели. Не подставляй ключ по шаблону «все ответы A».

Промпты доступны для копирования и скачивания в панели. Исходник — assets/prompts.js; эти копии обновляются командой `node scripts/write-prompts.mjs`.

Перед загрузкой проверь JSON в панели или командой `npm run exam:check -- файл.json`. Структурно верный файл всё ещё может содержать фактические ошибки ключа.

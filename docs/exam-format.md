# Формат экзамена NiuTest v1

Один JSON — один экзамен. Кодировка UTF-8. Пример: `assets/exam-template.json`; схема: `assets/exam.schema.json`. Проверка: `npm run exam:check -- файл.json` или панель. Импортёр дополнительно проверяет уникальность id, индекс относительно числа вариантов и одинаковые тексты вариантов без учёта регистра/крайних пробелов.

| Поле экзамена | Смысл |
| --- | --- |
| schemaVersion | Число `1` |
| id | Стабильный идентификатор, например `biology-2026` |
| title | Название до 200 символов |
| description | Описание до 2000 символов, необязательно |
| language | Язык вопросов, например `kk`, необязательно |
| sourceName | Имя документа, необязательно |
| sections | Код → название: `{ "cells": "Клетки" }` |
| questions | 1–5000 вопросов |

| Поле вопроса | Смысл |
| --- | --- |
| id | Уникальный внутри экзамена стабильный id |
| section | Код раздела; по умолчанию `general` |
| number | Положительный исходный номер; по умолчанию позиция |
| question | Текст вопроса, переносы строк допустимы |
| options | 2–12 разных непустых строк, исходный порядок |
| correctIndex | Индекс правильного варианта **с нуля** или `null` |
| answerStatus | `provided`, `verified`, `inferred`, `needs-review` |
| explanation | Объяснение, необязательно |
| note | Оговорки, необязательно |
| sourceUrl | http/https; обязательно для `verified` |

`provided` — перенесённый ключ, `verified` — проверка по источнику, `inferred` — вывод по содержанию, `needs-review` — ответ нельзя оценивать. Отсутствующий ключ становится `null / needs-review`, первый вариант не выбирается автоматически. Даже при указанном индексе `needs-review` исключает вопрос из оценки.

ID: 1–80 латинских букв, цифр, дефисов или подчёркиваний, первый символ — буква/цифра. Зарезервированы имена свойств Object.prototype (`constructor`, `toString` и др.) и `prototype`; `index` нельзя использовать как id экзамена, `all` — как раздел. Одинаковые id вопросов в разных экзаменах допустимы.

Вопрос, вариант, explanation/note — до 20 000 символов каждый. HTML показывается как обычный текст. Изображения, свободный ввод и несколько правильных вариантов не поддерживаются.

## FQuiz

```json
[
  {
    "question": "Сколько будет 2 + 2?",
    "options": [
      { "text": "3", "isCorrect": false },
      { "text": "4", "isCorrect": true }
    ]
  }
]
```

В панели укажи название или используй имя файла. Каждый isCorrect — boolean. Один true становится ключом, ноль true — неизвестным ответом, несколько true — ошибкой. Смешивать строки и объекты вариантов нельзя.

При обновлении сохраняй id. Новый id означает новый экзамен/вопрос. Порядок задаётся массивом. Утверждение «проверено моделью» само по себе не подтверждает правильность ключа.

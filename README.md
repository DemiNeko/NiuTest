# NiuTest — подготовка к тесту AI и Go

Статический сайт для GitHub Pages с 189 вопросами из предоставленного Word-документа: 100 по AI и 89 по Go и AI. Интерфейс на русском, оригинальные вопросы на казахском.

## Возможности

- Тренировка: выбор раздела и количества вопросов, немедленная проверка ответа.
- Экзамен: таймер, возможность менять ответы, итоговый разбор. Таймер не сбрасывается после перезагрузки.
- Перемешивание вопросов и вариантов с сохранением привязки к правильному ответу.
- Поиск по вопросам и ответам, избранное, работа над ошибками и пропусками.
- Сохранение прогресса и текущей попытки в localStorage.
- Адаптивный интерфейс и управление с клавиатуры.

## Правильные ответы

В Word нет официального ключа. Все 189 заданий просмотрены по содержанию: ожидаемый ответ в исходном порядке — A. Это проверенный по содержанию учебный ключ, но он не является официальным ключом преподавателя. В тренировке варианты перемешиваются.

Важные оговорки показаны рядом с ответами. Например, Go № 53: `len()` для строки возвращает число **байтов**, а не символов. В тесте A — ближайший и явно ожидаемый вариант; его неточная формулировка сохранена для соответствия документу. Go № 58: goroutine означает конкурентное выполнение, не гарантию параллельного выполнения. В Go № 89 только три варианта — четвёртый не добавлен.

Источники: [спецификация Go](https://go.dev/ref/spec), [команды Go](https://pkg.go.dev/cmd/go), [глоссарий ML Google](https://developers.google.com/machine-learning/glossary), [NIST AI RMF](https://www.nist.gov/itl/ai-risk-management-framework). Ссылки также доступны на странице «О тесте и ответах».

## Локальный запуск

Нужен Node.js 22 или новее. Зависимости устанавливать не требуется.

```sh
npm run dev
```

Открыть `http://127.0.0.1:4173`. При занятом порте задать переменную `PORT`. Открытие `index.html` через `file://` не поддерживается из-за загрузки JSON и JavaScript-модулей.

```sh
npm test
npm run build
```

Готовый сайт появляется в `dist/`. Публикуются только `index.html`, `.nojekyll` и `assets/`.

## GitHub Pages

Репозиторий: [DemiNeko/NiuTest](https://github.com/DemiNeko/NiuTest).

В `Settings → Pages → Build and deployment → Source` выбрать `GitHub Actions`. Workflow `.github/workflows/pages.yml` проверяет данные и логику, собирает сайт и публикует его при push в `main` или `master`. Также доступен ручной запуск.

Ожидаемый адрес после успешной публикации: `https://demineko.github.io/NiuTest/`. Все пути относительные, чтобы сайт работал в подпапке репозитория. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Структура и данные

- `assets/questions.json` — вопросы, исходные варианты, `correctIndex`, примечания.
- `assets/engine.js` — перемешивание, оценка, статистика и проверка сохранённых данных.
- `assets/app.js`, `assets/styles.css`, `assets/niutest.css` — интерфейс.
- `scripts/import_questions.py` — воспроизводимый импорт исходного DOCX стандартной библиотекой Python.
- `tests/engine.test.mjs` — проверки целостности данных, оценки и восстановления попытки.

Повторный импорт:

```sh
python scripts/import_questions.py "/path/to/Microsoft Word Document.docx"
```

Исходный Word не публикуется. Скрипт проверяет структуру именно предоставленного теста и отклоняет неожиданное число вопросов/вариантов. При замене теста также нужно заново проверить ключ ответов.

Данные обучения не отправляются на сервер. Шрифт Manrope загружается с Google Fonts; при недоступности используется системный шрифт. Нет синхронизации между устройствами. Экзамен — учебный: настройки времени и количества вопросов не воспроизводят неизвестный регламент реального теста.

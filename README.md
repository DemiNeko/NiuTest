# NiuTest — подготовка к экзаменам

Главная — выбор экзамена, как в [FQuiz](https://github.com/DemiNeko/FQuiz). Одно нажатие открывает **все вопросы** экзамена. Выбор варианта сразу показывает результат, правильный ответ и объяснение. Вопросы и варианты перемешиваются; переход дальше — вручную. Повторное нажатие не увеличивает статистику. Незавершённая попытка сохраняется после перезагрузки.

Левое меню закрыто по умолчанию. Дополнительные возможности: все вопросы с поиском и мгновенной проверкой, карточки, ошибки, избранное, настройка практики, проверка с таймером и статистика. При проверке с таймером ответы открываются в конце; время продолжает идти при закрытии страницы.

## Запуск и проверка

Нужен Node.js 22+. Зависимостей нет.

```sh
npm run dev
npm test
npm run build
```

Адрес: `http://127.0.0.1:4173`. Другой порт — через `PORT`. Готовый сайт — `dist/`. Пути относительные, поддерживается подпапка GitHub Pages. Через `file://` загрузка JSON/ES-модулей не работает.

Если среда запрещает дочерние процессы (`spawn EPERM`):

```sh
node --test --experimental-test-isolation=none tests/*.test.mjs
```

## Панель: экзамены и вопросы

Кнопка ⚙ открывает **«Экзамены и вопросы»** (`#import`).

1. Перетащи JSON-файлы, выбери их или вставь JSON от модели.
2. Проверь предпросмотр: название, число вопросов, предупреждения, ошибки с номерами.
3. Нажми **«Скачать каталог для сайта»**. ZIP содержит `src/exams/index.json` и все текущие и новые экзамены. Личного прогресса в нём нет.
4. Распакуй ZIP в корень репозитория с заменой соответствующих файлов и опубликуй изменения. Экзамены станут доступны всем.

**«Сохранить в этом браузере»** добавляет личный набор без публикации. Даже при нехватке места в браузере можно скачать проверенный общий каталог из предпросмотра.

Сайт статический: серверной учётной записи администратора и записи в GitHub из браузера нет. Панель подготавливает файлы; публикацию выполняет владелец репозитория. Посетители не могут изменять общий каталог. Для прямой загрузки «сразу всем» без обновления репозитория потребуется сервер с авторизацией и хранилищем.

## Папка src: общие настройки и материалы

```text
src/
  site.json                 Название, логотип, фон, верхняя надпись
  images/
    logo.svg                Логотип по умолчанию
    background.svg          Пример фона
  exams/
    index.json              Каталог экзаменов
    ai-go.json              Исходные 189 вопросов
    zhasandy-intellekt-208.json  Жасанды интеллект жүйелері — 208 вопросов
```

Исходный AI & Go сохранён полностью: 100 AI + 89 Go. Официального ключа в документе не было; ответы определены по содержанию и помечаются `inferred`. Уточнения к Go № 53 (`len()`), № 58 (goroutine), № 89 (три варианта) сохранены. Старое хранилище `qadam-progress-v1` переносится в экзамен `ai-go`, исходный ключ не удаляется.

«Жасанды интеллект жүйелері» добавлен из документа `Жасанды интеллект жүйелері (1).docx`: все 208 вопросов и 1040 вариантов перенесены без изменения текста и порядка, включая повторяющиеся вопросы. Номера 1–208 соответствуют позиции в документе. Проверка ответов выполнена 28 октября 2026 года: у каждого вопроса есть ссылка на источник; 194 ответа имеют статус `verified`, 14 — `inferred` для выбора по смыслу или неточных формулировок. Официального ключа преподавателя в документе нет. Во всех 208 заданиях выбран первый исходный вариант после проверки содержания, а не автоматически по позиции. Короткие уточнения находятся в `explanation` и показываются при раскрытии ответа. Новый экзамен имеет отдельный id и хранилище прогресса.

Старый AI & Go скрыт с помощью `hidden: true` в `src/exams/index.json`: он не показывается на главной и в переключателе экзаменов. Его вопросы, прогресс и поддержка резервных копий сохранены. Экспорт каталога сохраняет этот флаг; чтобы снова показать экзамен, удалите флаг и опубликуйте изменения.

Альтернатива панели:

```sh
npm run exam:check -- path/to/exam.json
npm run exam:add -- path/to/exam.json
npm run exam:add -- path/to/fquiz.json --id biology --title "Биология"
npm run exam:add -- path/to/biology.json --replace
```

CLI использует тот же валидатор. Он пишет файл в `src/exams/` и обновляет каталог. Существующий id не перезаписывается без `--replace`; `ai-go` зарезервирован для оригинала. Можно добавить файл вручную и строку `{ "id": "biology", "title": "Биология", "file": "biology.json" }` в массив `exams` файла `src/exams/index.json`. Сборка проверяет весь каталог.

## Формат и промпты

- [Пример JSON](assets/exam-template.json).
- [JSON Schema](assets/exam.schema.json).
- [Описание формата](docs/exam-format.md).
- [Три промпта для моделей](docs/prompts/README.md): конвертация, поиск ответов, независимая проверка. Доступны также в панели.

Поддерживаются вопросы с **одним правильным вариантом**, 2–12 вариантов. `correctIndex` отсчитывается **с нуля**. Для неизвестного ответа: `correctIndex: null`, `answerStatus: "needs-review"`. Он остаётся в списке, но не оценивается и не попадает в карточки. Несколько верных вариантов, свободный ввод и вопросы с обязательными изображениями пока требуют адаптации.

Принимаются NiuTest JSON и массивы FQuiz с `options: [{ "text": "…", "isCorrect": true }]`. UTF-8 BOM и одна полная Markdown-обёртка JSON удаляются. Обрезанные файлы, повторяющиеся id, одинаковые варианты, неверные индексы, конфликтующие ключи и небезопасные ссылки отклоняются. Структурная проверка не доказывает фактическую правильность ключа.

Лимиты: 5 МБ и 5000 вопросов на экзамен; до 20 файлов общим размером 20 МБ за один импорт. Список отображается страницами по 20 вопросов; основной экзамен охватывает весь набор. Браузер сам определяет квоту личного хранилища. Отказ сохранения не считается успешным импортом. Пакет записывается только после проверки всех файлов.

## Оформление для всех посетителей

Вкладка **«Оформление»** (`#admin`) позволяет настроить название, подпись в меню, логотип, надпись над заголовком, заголовок и описание главной, фон и его видимость, текст «ТВОЁ ПРОСТРАНСТВО ДЛЯ УЧЁБЫ» и его отображение.

Панель загрузки доступна напрямую по `#import`: кнопки добавления на главной и в навигации скрыты. Дополнительные разделы бокового меню свёрнуты. Язык интерфейса переключается в верхней панели: RU / EN / ҚАЗ, выбор сохраняется в браузере. Тексты вопросов и ответов остаются исходными.

В `src/site.json` доступны `accentColor`, `buttonColor`, `buttonHoverColor`, `buttonTextColor` (формат `#RRGGBB`) и `defaultLanguage` (`ru`, `en`, `kk`). Переводы главных надписей редактируются в `translations.en` и `translations.kk`, русские — в корне файла. Подробнее: [настройки контента](src/README.md).

Предпросмотр не меняет сайт для других. Скачай `site.json` и замени `src/site.json` либо выполни:

```sh
npm run site:apply -- path/to/site.json
```

После публикации настройки станут общими. Файлы можно заменять прямо в `src/images/`, меняя пути в `src/site.json`. Например: `"background": "./src/images/background.svg"`. Логотип по умолчанию — `./src/images/logo.svg`.

Панель принимает PNG/JPG/WebP: логотип до 1 МБ, фон до 2 МБ. Они встраиваются в скачанный JSON, отдельно переносить их не нужно. SVG можно положить в репозиторий. Допустимы ссылки http/https; они зависят от доступности внешнего сервера. Пустой background отключает фон.

## Прогресс и резервная копия

У каждого экзамена свои ответы, ошибки, закладки, карточки и попытка. Классический экзамен и настроенная практика делят текущую попытку; её замена требует подтверждения. Самооценка карточек не влияет на точность. «Последний ответ верный» не означает гарантированного запоминания.

Личный импорт с тем же id обновляет набор. Сохраняется статистика вопросов с прежними id, текстом, вариантами и ключом. При изменении содержания очищаются история, карточки и активная попытка; изменённые вопросы теряют старую статистику.

Панель → **«Резервная копия и перенос»** сохраняет личные экзамены и весь прогресс. Восстановление проверяется целиком, затем требует подтверждения замены. Для встроенных экзаменов нужна соответствующая версия общего каталога: резервная копия содержит их прогресс, но не дублирует опубликованные вопросы. Незавершённая запись восстанавливается из журнала; при ошибке хранилища импорт откатывается. Изменения другой вкладки требуют перезагрузки, чтобы не затереть её сохранение.

Данные не отправляются на сервер. Очистка браузера удалит личную библиотеку; сохраняй копии. «Сырые данные» выгружают ключи NiuTest для ручного восстановления повреждённого хранилища, такой файл не подходит для обычной кнопки восстановления. Синхронизации между устройствами нет.

## Публикация и устройство

В GitHub `Settings → Pages → Source` выбери `GitHub Actions`. Workflow `.github/workflows/pages.yml` запускает тесты, сборку и публикацию при push в `main`/`master` или вручную. Публикуется `dist/`, включая `assets/` и `src/`.

Интерфейс: `assets/app.js`, `assets/styles.css`. Логика: `engine.js`, `exam-format.js`, `library-store.js`, `catalog-export.js`, `site-config.js`. `scripts/import_questions.py` оставлен только для воспроизводимого извлечения исходного AI & Go DOCX; это не универсальный импортёр.

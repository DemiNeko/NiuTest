# Общий контент сайта

- `site.json` — общие название, логотип, фон и верхние подписи.
- `accentColor`, `buttonColor`, `buttonHoverColor`, `buttonTextColor` — цвет акцентов, кнопок, кнопок при наведении и текста кнопок. Формат: `#RRGGBB`. Цвета правильных и ошибочных ответов остаются зелёным и красным.
- `defaultLanguage` — язык нового посетителя: `ru`, `en` или `kk`. Выбор посетителя сохраняется в его браузере.
- `translations.en` и `translations.kk` — переводы надписей главной и верхней панели: `tagline`, `topbarText`, `homeEyebrow`, `homeTitle`, `homeSubtitle`. Русские надписи находятся в корне файла. Если перевод поля отсутствует, используется корневой текст; пустая строка скрывает подпись. Тексты вопросов, варианты, названия и описания экзаменов не переводятся автоматически.
- `images/logo.svg` — логотип; можно заменить PNG/JPG/WebP/SVG и обновить путь в site.json.
- `images/background.svg` — пример фона. Для включения: `"background": "./src/images/background.svg"`.
- `exams/index.json` — общий каталог; каждый файл в exams содержит один экзамен.

Панель «Экзамены и вопросы» открывается по прямому адресу `/#import` (на GitHub Pages: `/NiuTest/#import`) и выгружает ZIP с готовым src/exams. Распакуй в корень репозитория. Вкладка «Оформление» (`#admin`) выдаёт site.json и сохраняет имеющиеся переводы при экспорте. Изменения станут общими после публикации. Переводы редактируются непосредственно в site.json. Тексты промптов для моделей сохранены в исходном русском варианте.

На главной скрыты добавление экзамена, резервная копия и футер. Кнопки добавления и управления убраны из верхней панели. В боковом меню дополнительные разделы свернуты по умолчанию. Это упрощение интерфейса, а не ограничение доступа: сайт остаётся статическим, публиковать общие изменения может владелец репозитория.

Перед публикацией: `npm test`, `npm run build`. Папка публичная: не помещай сюда личные ответы, резервные копии прогресса и секреты.

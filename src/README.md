# Общий контент сайта

- `site.json` — общие название, логотип, фон и верхние подписи.
- `images/logo.svg` — логотип; можно заменить PNG/JPG/WebP/SVG и обновить путь в site.json.
- `images/background.svg` — пример фона. Для включения: `"background": "./src/images/background.svg"`.
- `exams/index.json` — общий каталог; каждый файл в exams содержит один экзамен.

Панель «Экзамены и вопросы» выгружает ZIP с готовым src/exams. Распакуй в корень репозитория. Вкладка «Оформление» выдаёт site.json. Изменения станут общими после публикации.

Перед публикацией: `npm test`, `npm run build`. Папка публичная: не помещай сюда личные ответы, резервные копии прогресса и секреты.
